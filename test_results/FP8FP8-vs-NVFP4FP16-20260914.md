# FP8+FP8 vs NVFP4+FP16 对打（2026-09-14）

同一镜像 FastLLM official-wheel，MTP3，关思考，单并发。A：FP8 权重 + FP8 KV + 210K。B：NVFP4 权重 + FP16 KV + 240K。题集 SHA256 与 9/12 门禁相同。

## 判定

- 考试智商平手：A 64.18% / B 64.15%，差 0.04pp
- NIAH 都是 **15/15**（64K / 128K / 200K 全中）
- 比 9/12 的 NVFP4+FP8（NIAH 8/15）明显好，说明当时找针差主要不是「NVFP4 权重变笨」；关思考 + 当场两套都能找全
- API 错误：两边都是 0；看门狗全程无 OOM
- 200K 针连打 3 次：A 3/3，B 3/3。A 的 smoke.ok=false 只因为短句回了 `ping` 而不是 `pong`，不影响稳定性
- **日常留下：NVFP4 + FP16 KV + 240K 关思考**（平手按方案维持 B；找针不弱于 A，预填充还快一截）

门禁：`suite_complete` / `no_api_errors` / 综合比 99.94% / 单项掉点均未超 3pp → `production_pass=true`
