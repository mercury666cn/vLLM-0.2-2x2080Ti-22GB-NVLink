## CPU 是否值得换

FP8 全量评测连续采样 6030 点：

- 进程 CPU 约 4.5 核（445%），折合整机 **6.2%**，峰值 7.3%
- 负载约 4.5 / 72
- GPU0 利用率均值 94%，峰值 100%

当前是 GPU 带宽和内核在干活，不是 CPU。换更新的 CPU 对单并发推理几乎没有可见收益。
