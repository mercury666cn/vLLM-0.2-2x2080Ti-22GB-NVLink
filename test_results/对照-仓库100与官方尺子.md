# 仓库 100 tok/s vs 这次测速

## 结论

DFlash **开了投机**，不是没开。它不叫 MTP，叫 DFlash draft。上线为了 128K 稳定，draft 只开到 **3**。

仓库说的 100，不是这台机器、也不是 llm_speedtest 这套哲学短文能打出来的数。

## 同一把官方尺子（刚测）

提示词 128/512/1024/2048/4096，输出 128，并发 1。

| 长度 | DFlash draft=3 | 现网 vLLM MTP3 |
| ---: | ---: | ---: |
| 128 | 59.0 | 50.5 |
| 512 | 62.1 | 66.3 |
| 1024 | 59.0 | 49.4 |
| 2048 | 63.0 | 64.4 |
| 4096 | 58.8 | 48.9 |

这把尺子上两边都在 **50–66**，DFlash 更稳一点，没有质变。

## 仓库那句 100 从哪来

1. **vLLM-2080Ti 仓库宣传**：参考机（单核更强）短英文。本机 9 月 7 日同口径实测 vLLM 只有 **69.6**，不是 100。
2. **DFlash 视频/跑分**：英文短续写 + draft 5/7。本机测过 **draft5=147、draft7=201**。中文思考仍是 **50–64**。
3. **本次生产 DFlash**：draft=3，英短冒烟约 **100**；官方测速题约 **59**。draft=3 已经接近或低于 vLLM 短英文的 70。

## 为什么官方页看起来不到 60

- 题是哲学短文，不是「继续写这段英文凑满 400」。
- 输出只有 128，起步损耗占比大。
- ITL 约 41ms、每步大约吐 2.3 个 token → 正好 55 tok/s。这就是 draft=3 的接受率，不是没开投机。
- 客户端计时，含约 40ms 局域网。

要打 100+，得回到英文短续写 + draft 5/7，并接受 128K 稳定性风险。日常中文对话不会变成 180。
